# Wallos 5.7.1 兼容整合说明

本次以官方稳定标签 `v5.7.1`（2026-09-10，`52820e8`）为目标，整合 `v5.4.5..v5.7.1` 增量。版本为 `v5.7.1-remastered.1`。Remastered 仍是独立维护分支，不支持直接换成官方镜像启动现有数据库。

| 官方改动 | Remastered 的处理 |
| --- | --- |
| 首页待付款数量可设置为 3/5/10/20 | 接入显示设置，默认 3；查询增加用户、回收站和一次性购买过滤 |
| 首页即将取消的订阅、统计页潜在节省 | 接入定制首页和统计布局，点击沿用现有详情弹窗，截图模式同步处理新卡片 |
| Markdown 备注和快捷工具栏 | 保留定制备注、图片和价格规则编辑区，增加粗体/斜体/列表/链接按钮；详情采用 Parsedown safe mode；现有扩展 Markdown 渲染接口保留 |
| 备注存储迁移 | 不执行官方 58 的批量解码；本分支已有存储后单次解码约定，避免旧备注重复解码或字符损坏 |
| 注销、密码重置、邮件验证、2FA | 吸收成功检查及 2FA 启停事务；保留现有认证、限速、CSRF、TOTP 时间步防重放和并发备份码消费机制 |
| 内网 Webhook 白名单向普通用户开放 | 新增管理员显式开关，默认关闭；开启仍必须逐个命中白名单，SMTP 的独立地址校验保持不变 |
| OIDC 在 CDN/多地址域名后的连接 | 校验每个候选地址，cURL 只连接已校验地址；保留原有环境配置、端口检查和错误信息边界 |
| 付款方式引用保护及 Logo 抓取错误 | 使用数量大于零的引用检查；禁止删除被引用付款方式；保留受限抓取和真实失败原因 |
| 保存前删除失败、汇率重复请求 | 吸收删除结果检查；当天已刷新时不重复调用汇率服务，现有刷新策略仍保留 |
| 统计分类排序、缺失统计分组 | 按实际 order 列排序；关联分类、付款人或付款方式缺失时不产生未定义键警告 |
| 删除账户与清理 Logo | 保留更完整的事务式用户数据清理、180 天回收站、媒体审计及显式清理；不引入官方删除时即时清理 Logo 的路径 |
| CSV/iCalendar 导出 | CSV 正确转义换行、引号和逗号；iCalendar 增加 UTF-8 安全折行及 CRLF，保留现有转义及脱密导出阻断 |
| PWA Manifest 与离线缓存 | 动态 Manifest 支持深浅主题，旧 manifest.json 地址转交动态响应；私有 no-store。保留定制 Service Worker 的精确资源指纹，不离线缓存登录页面、接口和私有媒体 |
| 备份上传上限 | Nginx/PHP 对齐，允许 256 MB 文件并为表单预留空间；恢复校验、事务和回滚不变 |
| 阿塞拜疆语、韩语与新词条 | 新增 az，整合韩语改进；29 种语言沿用英文兜底，简繁中文保持完整目录 |

## 数据迁移与发布

官方迁移 56/57 与本分支历史编号冲突，合并为新的幂等 `000082.php`：仅增加 `admin.allow_standard_users_local_webhooks` 和 `settings.upcoming_payments_limit`，不改订阅、价格、备注和支付记录。启动验证与健康检查同步要求迁移 82。

本次将上游稳定标签作为合并父提交记录，后续可基于正式共同祖先继续做增量兼容整合。公开标签使用 Remastered 自己的版本，不冒充官方镜像或官方 Release。

发布前在生产 SQLite 的隔离副本上执行迁移和浏览器测试，关闭副本定时任务。生产发布前保留在线数据库快照、Compose 配置、原镜像和代码版本；本次无媒体迁移。回滚应用可使用上一版镜像，新列向后兼容；如需恢复数据库快照，必须先核对发布后的新增业务数据，避免覆盖。

测试临时数据库、浏览器下载、截图和候选容器集中到任务专用临时目录；完成后删除。正式回滚备份与旧生产镜像属于恢复资料，保留。
