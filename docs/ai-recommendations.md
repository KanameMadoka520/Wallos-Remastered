# AI 建议与分类翻译

本分支保留按账户配置的 AI 功能，提供订阅分析建议和分类翻译预览。它与 MCP 的授权相互独立：AI 服务商密钥用于调用模型，Wallos Agent API 密钥用于让外部 Agent 访问 Wallos；两者不能混用。开启 AI 不会自动授予模型修改账本、付款记录或订阅的权限。

## 设置与服务商

打开 **设置 → AI 建议**，启用功能，选择服务商，填写必要的地址和密钥，测试连接并选择模型，最后保存。更换模型、地址或密钥后也需要保存，分类翻译和建议生成读取的是服务器中已保存的配置。

| 服务商 | 地址与密钥 |
| --- | --- |
| ChatGPT | 使用 OpenAI 官方地址，填写对应的 API 密钥。 |
| Gemini | 使用 Google 官方地址，填写对应的 API 密钥。 |
| OpenRouter | 使用 OpenRouter 官方地址，填写对应的 API 密钥。 |
| Local Ollama | 填写 Ollama 根地址，例如 `http://ollama:11434`，不添加 `/api/generate`。 |
| OpenAI Compatible | 填写兼容服务的 API 根地址，例如 `https://ai.example.invalid/v1`，不添加 `/chat/completions`；是否需要密钥取决于服务配置。 |

模型清单和推理请求共用外发访问校验：禁止自动跳转，固定已验证的 DNS 解析结果，设置连接与总时限，并限制返回体。局域网、自建模型或 Docker 网络中的服务需要由管理员在安全设置的 SSRF 允许列表中填写准确的 `主机[:端口]`，也可以由部署方通过 `SSRF_ALLOWLIST` 环境变量管理该列表。普通账户还需要管理员开启“允许普通用户使用 Webhook 白名单”选项（`allow_standard_users_local_webhooks`）；该选项与主机允许列表必须同时满足。普通账户不能凭一个 URL 绕过访问控制，也不能自行修改管理员允许列表。不要为了接入模型放开所有内网地址。接口错误不会把服务商原始响应、密钥或请求头直接显示给用户。

模型的实际计费、可用额度、响应速度和质量由服务商决定。Wallos 不保证 AI 判断正确，也不会根据建议自动取消真实服务或改变价格。

## 订阅建议

在 **设置 → AI 建议** 点击生成建议按钮，或在同一区域选择已有的定时生成安排。手动和定时任务使用同一套客户端及响应校验；模型返回出错、格式无效，或生成期间相关订阅与 AI 设置发生变化时，保留原有建议，稍后重新生成。

建议生成会把当前账户内订阅的名称、价格、币种、周期、多分类、多付款人和当前优惠信息发送给所选 AI 服务商，因此请在启用前确认这些资料适合交给该服务处理。实际付款历史中的金额、币种和备注不外发；付款账本仅在服务器本地参与并发快照校验。关闭 AI 或不配置定时安排可以停止后续自动请求；已经交给服务商的数据仍适用其保留政策。

## 分类翻译：先预览，再确认

打开 **设置 → 分类 → 使用 AI 翻译分类**，选择“生成翻译预览”。目标语言是账户已保存的界面语言。这个功能同样支持翻译回英语；保存新的账户语言不会自动重命名任何分类。

翻译请求只包含当前账户可翻译分类的 ID、名称及目标语言，不包含订阅明细、账本、付款历史、其他账户的分类或服务商密钥。保留的“无分类”占位项不参与翻译。AI 把分类名称作为待翻译文本处理，分类名称或模型响应中的指令不会被作为工具调用执行。

页面会并列显示当前名称和建议译名。只有点击“确认应用这些译名”才会修改名称；关闭预览不修改任何数据。应用只修改现有分类的名称，不新建或删除分类，不改变订阅与分类的关联，也不会改动其他账户的数据。AI 译名可能不合适，确认前应逐项查看。

服务器要求模型返回完整、无重复、无额外项的精确 ID 集合。译名必须是有效 UTF-8 文本、非空、无控制字符，长度最多 100 个字符。任意一项校验失败会拒绝整个结果。名称按项目现有约定只解码一次、存储时转义一次，浏览器通过文本节点显示模型结果；看起来像 HTML 的内容也只是文字。

预览绑定当前登录会话和账户，10 分钟后到期。服务器保存已验证的译名；应用请求只提交不可猜测的预览令牌，不能自行提交一份新译名。服务器在应用时核对完整分类快照、账户语言、AI 服务商/模型/密钥/地址等配置，并在 SQLite 事务中一次性更新。期间增删分类、重命名、排序、切换语言、禁用 AI 或修改配置均要求重新预览，避免覆盖其他操作。写入失败会整体回滚。同一已成功请求因网络问题重试时不会再次覆盖后续改动。

分类页面存在未保存的编辑，或预览后又改了页面上的名称时，页面会要求先保存、刷新并重新预览。截图脱敏模式会在服务器阻止翻译预览和应用，分类区域不输出真实名称；关闭脱敏模式后可以使用。

已有的“重置默认名称为当前语言”仍是独立操作，只匹配项目内置默认名称的已知变体，不调用 AI。自定义名称需要使用翻译预览或手动修改。

## 故障处理

- **提示先配置 AI：** 启用 AI，测试并选择模型，然后保存设置。仅改变浏览器控件尚未生效。
- **连接失败：** 检查地址格式、服务商密钥、余额、模型访问权和管理员的外发访问允许列表。请求被拒绝或超时会保留原数据。
- **译名不完整或无效：** 重试或选择更适合结构化输出的模型。系统不会“尽量应用”一部分译名。
- **预览过期或数据变化：** 保存需要保留的编辑，刷新页面，再生成预览。
- **截图脱敏模式已开启：** 先关闭模式。脱敏模式用于安全展示，不能通过翻译接口取得真实分类名称。

## 维护与验证

本功能不需要数据库迁移，也不会修改现有 MCP 字段约定。共享 AI 客户端位于 `includes/ai_client.php`；分类翻译校验与事务位于 `includes/ai_category_translation.php`；浏览器端点位于 `endpoints/ai/translate_categories.php`。端点要求已认证账户、POST 与有效浏览器 CSRF 令牌，不是匿名接口，也不是新的 MCP 工具。

开发者可以在独立 fixture 上运行 `tests/ai_category_translation_test.php`、`tests/ai_category_translation_http_test.py` 和 `tests/e2e/ai_category_translation_smoke.mjs`。它们覆盖精确响应集合、账号隔离、并发冲突、事务回滚、文本转义、预览确认和截图隐私。HTTP 专项同时验证 ntfy 测试通知的 2xx/错误/超时结果；ntfy 连接时限为 5 秒，总时限为 15 秒，非 2xx 返回不会显示发送成功。所有写入检查必须使用临时数据库和测试账户，不能针对生产账本运行。

完整复现时，先按现有测试约定建立 `agent-ui-test` / `upstream-test-2` 两账户 fixture，并把测试目录只读挂载为容器内 `/wallos-tests`。在该容器回环地址启动专用 mock（与建议生成专项的 `18191` 端口独立）：

```bash
docker exec -d -e PHP_CLI_SERVER_WORKERS=4 wallos-ai-fixture \
  php -S 127.0.0.1:18192 /wallos-tests/fixtures/ai_category_provider_router.php

export WALLOS_UPSTREAM_TEST_URL=http://127.0.0.1:18284
export WALLOS_UPSTREAM_FIXTURE_FILE=/path/to/private-fixture/upstream-fixture.json
export WALLOS_FEATURE_TEST_DB=/path/to/private-fixture/wallos.db
python3 tests/ai_category_translation_http_test.py
npm run e2e:ai-categories
```

端口、容器名和挂载路径按实际 fixture 调整。两个专项会临时配置当前 fixture 的 AI 设置及外发允许列表，使用测试名称，最后恢复原设置与分类名称；应按顺序运行，避免与同一测试账户的其他偏好测试并行。它们不调用真实付费模型服务。PHP 纯逻辑测试使用内存数据库，可单独在带 SQLite3、mbstring 的 PHP 容器中执行。
