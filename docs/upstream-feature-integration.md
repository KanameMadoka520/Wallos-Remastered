# 官方功能补齐与 Remastered 兼容方案

当前对应 `v5.10.4-remastered.3`（多关系/批量/推送自 remastered.1 引入），审阅目标为官方稳定标签 `v5.10.4`。此版本号表示功能同步目标，不表示与官方文件、数据库或镜像可互换。历史移植起点为 v5.7.1；此前安全和等价实现见 [选择性兼容记录](upstream-5.10.4-compatibility.md)。

## 功能对照

| 能力 | 本分支实现 | 验收重点 |
| --- | --- | --- |
| 多付款人 | 账号内家庭成员关联列表，保留主付款人；表单、详情、筛选、统计、导出和 MCP 接入 | 旧记录迁移、成员归属、等分统计、旧客户端不丢关联 |
| 多分类 | 完整有序分类列表及主分类；关系表兼容旧字段 | 筛选不重复、二级引用不能误删、复制/回收保留 |
| 批量操作 | 网页选择当前显示的明确记录；MCP 支持批量更新及移入回收站 | 预览、50 条上限、版本、防重、全批事务、逐项审计 |
| Web Push | 自愿启用，账号内按设备管理，独立 VAPID、设备撤销、推送去重 | 账户切换、退出、SSRF、锁屏隐私、worker 缓存边界 |
| AI 推荐与分类翻译 | 五提供商共享请求/解析；分类预览后显式应用 | 不完整输出、错误保密、过期预览、并发变更、全批回滚 |
| Logo 目录来源 | DuckDuckGo / Brave 之外增加 selfh.st、Dashboard Icons | 固定公共来源、有限缓存、原有媒体保存、截图隐私 |
| ntfy 测试 | 5 秒连接与 15 秒总超时，HTTP 2xx 成功 | 避免无限等待和错误成功反馈 |
| 上游缓存/UI 重构 | 使用本分支现有文件指纹、分页、Chart.js、转场和私有缓存规则 | 行为等价，避免整体覆盖定制页面 |
| 切换语言时自动改默认分类名称 | 新账号本地化及显式重置 | 用户保存的名称不随语言偏好静默改写 |

## 关系与统计

迁移 84 新增 `subscription_payers`、`subscription_categories`，包含顺序与引用索引，按现有主引用回填。保留 `subscriptions.payer_user_id`、`category_id`；第一项是主引用。重复迁移不清空已有列表。legacy 插入/主引用更新触发器兼容旧写入路径，删除触发器兼容少量关闭外键的维护路径。

付款人是当前 Wallos 账户下的家庭成员，不是其他登录用户；每个引用 ID 均须属于订阅所有者。没有扩大密钥权限或共享账户数据。

显式列表替换完整关联；省略列表和主引用则保留；仅提供旧主引用时将其提升首位并保留其余项。主引用与列表首项冲突时拒绝。详情、备份、导出、复制、回收站恢复保留全部列表。

总费用只计算一次；按付款人或分类的统计先等分，筛选选择多个成员时按匹配成员份数计算，避免重复连接导致倍增。实际付款记录、币种快照、原有优惠规则不随关系编辑重写。付款人分摊与分类分摊属于两种分析维度，不应把两种图表的金额相加。

MCP 订阅聚合版本覆盖关联列表，可发现只修改关联的并发编辑。详见 [Agent API](agent-api.md)。

## 批量写入

网页与 MCP 共用单条订阅业务逻辑。批量操作不建立隐藏 Agent 密钥，浏览器仍使用登录会话和 CSRF；浏览器防重记录在迁移 86 的账号归属表中。每批 1–50 个明确目标，先验证全部原始版本，再执行并最终重读结果。任一失败整体回滚，成功审计与防重响应和数据同事务提交。

支持提醒开关、提前天数、付款方式和分类；删除进入本分支 180 天回收站。界面明确只选当前可见记录，不将跨页/全筛选结果当作隐式目标。预览不锁定数据，执行前仍检查版本。网络响应不确定时保留请求标识以安全重试。

## Web Push

迁移 85 新增独立 VAPID、用户偏好、设备订阅和事件去重表；私钥不进入可广泛序列化的 admin 行。数据库备份包含这些私密配置，应继续受现有备份权限保护。默认不启用，也不显示订阅明细。具体浏览器设置、网络限制与运维见 [Web Push](web-push.md)。

保留现有 Service Worker 静态允许列表和私有接口禁止缓存规则，只增加推送及通知点击事件。保持现有其他通知渠道。设备 API 不向 MCP 暴露推送凭据。

## 升级、恢复和回退

启动迁移链和数据库校验要求 86；健康检查同时检查新增表和最新标记。使用原挂载目录升级，不替换生产数据库。还原旧备份后必须由新代码运行完整迁移，再开放访问；新备份会自然包含全部新增表及 VAPID 配置。

升级前保留一致性 SQLite 备份、原镜像和 Compose 配置。出现问题优先向前修复。已经使用多关系后，旧镜像的统计和界面无法完整理解新数据，不应直接恢复旧镜像并开放写入。确需回退时先停用写入、撤销/关闭新接口，备份当前数据，在隔离副本中确认旧 runner 的迁移清单、关系触发器及统计兼容性。迁移标记不能被随意删除；也不能恢复旧数据库覆盖上线后的新增记录。

## 后续同步方式

每个官方稳定版本核对安全、功能、数据结构和依赖变化，逐项标记已引入、已有等价实现或待补齐并说明验收条件。使用本机逻辑、HTTP 和浏览器测试，不新增 GitHub Actions。版本号不代替测试结果，也不承诺浏览器、第三方推送服务和任意代理环境全部一致。

## remastered.1 验证记录

所有新增/编辑/删除、故障注入和权限测试均使用专用一次性数据库。最终镜像的 NGINX/PHP-FPM 站点未挂载应用源码，另行运行新功能 HTTP/浏览器专项，避免仅测试宿主机代码。

- 静态契约 25 项、PHP 回归 49 组全部通过。
- Agent 业务 72 项；多关系 24 项；实际统计模块 5 个独立场景（含替代计划与滚动图）；批量 36 项；Web Push 76 项；新旧备份恢复 24 项。
- 最终镜像 HTTP/MCP 28 项、上游兼容 HTTP 24 项、实际 SQL 故障回滚 6 项。
- 新关系浏览器 22 项、批量浏览器 20 项、Web Push UI/API/worker 22 项、多关系隐私 11 项；另有隔离账号批量隐私 6 项。
- Agent 权限 UI 46 项，上游 XSS/日历 18 项；原有订阅、图片、客户端缓存、管理员备份、多语言、截图隐私及隐私 DOM 浏览器套件通过。
- 运行时安全 11 项保持通过；PHP 8.3.36 / Expat 2.10.0 和 FPM 限制保留。
- 生产数据库副本迁移演练：52 张原表内容不变、89 条付款人及分类关联回填、quick_check 与外键检查通过。

Web Push 的加密、权限和浏览器事件验证通过；真实浏览器厂商推送服务到实际设备的送达尚需用户在目标设备启用并验证，测试没有用模拟结果代替真实送达。

## 尚未接入或保留不同实现的项目

- Google 自定义搜索需要用户额外提供搜索引擎 ID 与密钥；当前保留无密钥搜索并增加两个目录。
- 官方 v2 REST 写入协议尚未提供一对一适配；外部 Agent 使用已有 MCP / Agent HTTP API。不能把不同协议的工具权限混为一谈。
- Android Touch to Search 仍需目标浏览器真机验证。
- 切换语言不静默改写已有分类名称；本轮显式 AI 翻译可处理自定义名称，并在应用前展示预览。官方 UI、图表和缓存文件保留本分支等价实现。

配置与操作说明见 [AI 推荐与分类翻译](ai-recommendations.md)、[Logo 目录](logo-sources.md)。本轮不增加迁移或扩大 MCP 权限。

- 静态契约 25 项、PHP 回归 53 组通过；AI 客户端 39 项、推荐 49 项、分类翻译 46 项包含在回归中。
- AI HTTP / 实际 CLI 定时入口 35 项、分类翻译及 ntfy HTTP 36 项通过；包括 weekly/monthly、单账号失败隔离、完整事务回滚、并发拒绝、超大响应和 15 秒超时。
- MCP / Agent HTTP 28 项、上游兼容 HTTP 24 项、多关系实际 SQL 故障回滚 6 项通过。
- 分类翻译真实浏览器 17 项、两个真实 Logo 公共目录和订阅/付款图标保存流程通过。
- 多关系、批量、Web Push、关系/批量隐私、上游兼容、Agent 权限、订阅、图片、客户端缓存、29 种语言、截图隐私及管理员浏览器回归通过。
- PHP 8.3.36、Expat 2.10.0-r0、Brotli 和 FPM 限制等运行时安全 11 项通过。

真实 AI 服务的额度与模型质量、真实设备 Web Push 送达仍由相应第三方及设备环境决定；本地 mock 用于验证协议、解析和故障处理，不替代实际服务质量或送达验证。

本机上线前保留一致性 SQLite 备份和原 Compose / 镜像；本次无新迁移，上线后 54 张业务与配置表的记录数及内容哈希全部一致，数据库 quick_check、外键检查通过。本地和公网健康/登录正常，MCP 无凭据保持 401。未在生产执行新增、修改或删除测试。

## 桌面整合验收

`remastered.3` 处理新增功能与原有主题的实际冲突。批量管理入口位于分页工具栏，展开后操作区占整行；选择框显示变化触发瀑布流重排。付款人/分类用紧凑复选下拉，原有带名称的多选 select 仍是表单唯一数据源，`payer_ids[]`、`category_ids[]` 及主引用顺序不变；无 JavaScript 时使用原生多选。

统计金额和说明按钮使用独立行，说明列表按可用宽度排列。日历名称最多两行，悬停/辅助标签保留完整信息，点击或 Enter/空格可查看完整详情，Escape 关闭并返回原焦点。紧凑日历弹窗的宽度不再影响付款、历史、回收站和金额说明。长标题为关闭按钮留出空间。

Web Push 长设备列表和 AI 分类翻译预览在组件内滚动；Logo 搜索保留搜索栏、关闭、来源和分页，将结果区单独滚动，随容器滚动重新定位。日历悬停标题、辅助标签和价格随截图脱敏同步隐藏并可恢复；金额说明在生成显示 JSON 时解码存量名称一次，浏览器继续转义输出。UI 变更不扩大网络、密钥、账号或 Service Worker 权限。

三个浏览器入口分别覆盖统计/日历/导航、订阅/批量/多选、设置/弹窗，固定检查 1366×768、1440×900、1920×1080；设置还包含深浅主题、20 台模拟设备和模拟 AI 翻译结果。

```bash
npm run e2e:desktop-layout
npm run e2e:subscriptions-desktop
npm run e2e:settings-desktop
```

仅对私有隔离实例运行。只读布局脚本接受 `WALLOS_BASE_URL` 与私有 `WALLOS_UI_SESSION_FILE`（`{"session":"短期会话"}`），也支持 `WALLOS_TEST_USERNAME` / `WALLOS_TEST_PASSWORD`。订阅桌面脚本必须提供 `WALLOS_UPSTREAM_TEST_URL`、`WALLOS_UPSTREAM_FIXTURE_FILE` 和 `WALLOS_AGENT_TEST_KEY_FILE`，并验证账号为合成 fixture 后才创建测试记录。不得对真实账号执行写入套件。Logo、推送和翻译矩阵使用模拟响应，不发送真实通知或付费 AI 请求。

自动几何检查必须配合实际截图审阅，覆盖默认、展开、滚动及长文本状态；只检查 DOM 存在或 HTTP 成功不足以验收。管理员真实数据仅用于授权的只读复查；包含账号数据、密钥或会话的临时数据库和报告留在受限目录，完成后删除临时凭据及副本，不提交截图或数据。
