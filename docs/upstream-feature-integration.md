# 官方功能补齐与 Remastered 兼容方案

本轮对应 `v5.10.4-remastered.1`，审阅目标为官方稳定标签 `v5.10.4`。此版本号表示功能同步目标，不表示与官方文件、数据库或镜像可互换。历史移植起点为 v5.7.1；此前安全和等价实现见 [选择性兼容记录](upstream-5.10.4-compatibility.md)。

## 功能对照

| 能力 | 本分支实现 | 验收重点 |
| --- | --- | --- |
| 多付款人 | 账号内家庭成员关联列表，保留主付款人；表单、详情、筛选、统计、导出和 MCP 接入 | 旧记录迁移、成员归属、等分统计、旧客户端不丢关联 |
| 多分类 | 完整有序分类列表及主分类；关系表兼容旧字段 | 筛选不重复、二级引用不能误删、复制/回收保留 |
| 批量操作 | 网页选择当前显示的明确记录；MCP 支持批量更新及移入回收站 | 预览、50 条上限、版本、防重、全批事务、逐项审计 |
| Web Push | 自愿启用，账号内按设备管理，独立 VAPID、设备撤销、推送去重 | 账户切换、退出、SSRF、锁屏隐私、worker 缓存边界 |
| 上游缓存/UI 重构 | 使用本分支现有文件指纹、分页、Chart.js、转场和私有缓存规则 | 行为等价，避免整体覆盖定制页面 |
| 切换语言时自动改默认分类名称 | 新账号本地化及显式重置 | 用户保存的名称不随语言偏好静默改写 |

## 关系与统计

迁移 84 新增 `subscription_payers`、`subscription_categories`，包含顺序与引用索引，按现有主引用回填。保留 `subscriptions.payer_user_id`、`category_id`；第一项是主引用。重复迁移不清空已有列表。legacy 插入/主引用更新触发器兼容旧写入路径，删除触发器兼容少量关闭外键的维护路径。

付款人是当前 Wallos 账户下的家庭成员，不是其他登录用户；每个引用 ID 均须属于订阅所有者。没有扩大密钥权限或共享账户数据。

显式列表替换完整关联；省略列表和主引用则保留；仅提供旧主引用时将其提升首位并保留其余项。主引用与列表首项冲突时拒绝。详情、备份、导出、复制、回收站恢复保留全部列表。

总费用只计算一次；按付款人或分类的统计先等分，筛选选择多个成员时按匹配成员份数计算，避免重复连接导致倍增。实际付款记录、币种快照、原有优惠规则不随关系编辑重写。付款人分摊与分类分摊属于两种分析维度，不应把两种图表的金额相加。

MCP 订阅聚合版本覆盖关联列表，可发现只修改关联的并发编辑。详见 [Agent API](agent-api.md)。

## 批量写入

网页与 MCP 共用单条订阅业务逻辑。批量操作不建立隐藏 Agent 密钥，浏览器仍使用登录会话和 CSRF；浏览器防重记录在迁移 86 的账号归属表中。每批 1–50 个明确目标，先验证全部原始版本，再执行并最终重读结果。任一失败整体回滚，成功审计与防重响应和数据同事务提交。

支持提醒开关、提前天数、付款方式和分类；删除进入本分支 180 天回收站。界面明确只选当前可见记录，不将跨页/全筛选结果当作隐式目标。预览不锁定数据，执行前仍检查版本。网络响应不确定时保留请求标识以安全重试。

## Web Push

迁移 85 新增独立 VAPID、用户偏好、设备订阅和事件去重表；私钥不进入可广泛序列化的 admin 行。数据库备份包含这些私密配置，应继续受现有备份权限保护。默认不启用，也不显示订阅明细。具体浏览器设置、网络限制与运维见 [Web Push](web-push.md)。

保留现有 Service Worker 静态允许列表和私有接口禁止缓存规则，只增加推送及通知点击事件。保持现有其他通知渠道。设备 API 不向 MCP 暴露推送凭据。

## 升级、恢复和回退

启动迁移链和数据库校验要求 86；健康检查同时检查新增表和最新标记。使用原挂载目录升级，不替换生产数据库。还原旧备份后必须由新代码运行完整迁移，再开放访问；新备份会自然包含全部新增表及 VAPID 配置。

升级前保留一致性 SQLite 备份、原镜像和 Compose 配置。出现问题优先向前修复。已经使用多关系后，旧镜像的统计和界面无法完整理解新数据，不应直接恢复旧镜像并开放写入。确需回退时先停用写入、撤销/关闭新接口，备份当前数据，在隔离副本中确认旧 runner 的迁移清单、关系触发器及统计兼容性。迁移标记不能被随意删除；也不能恢复旧数据库覆盖上线后的新增记录。

## 后续同步方式

每个官方稳定版本核对安全、功能、数据结构和依赖变化，逐项标记已引入、已有等价实现或待补齐并说明验收条件。使用本机逻辑、HTTP 和浏览器测试，不新增 GitHub Actions。版本号不代替测试结果，也不承诺浏览器、第三方推送服务和任意代理环境全部一致。

## 本轮验证记录

所有新增/编辑/删除、故障注入和权限测试均使用专用一次性数据库。最终镜像的 NGINX/PHP-FPM 站点未挂载应用源码，另行运行新功能 HTTP/浏览器专项，避免仅测试宿主机代码。

- 静态契约 25 项、PHP 回归 49 组全部通过。
- Agent 业务 72 项；多关系 24 项；实际统计模块 5 个独立场景（含替代计划与滚动图）；批量 36 项；Web Push 76 项；新旧备份恢复 24 项。
- 最终镜像 HTTP/MCP 28 项、上游兼容 HTTP 24 项、实际 SQL 故障回滚 6 项。
- 新关系浏览器 22 项、批量浏览器 20 项、Web Push UI/API/worker 22 项、多关系隐私 11 项；另有隔离账号批量隐私 6 项。
- Agent 权限 UI 46 项，上游 XSS/日历 18 项；原有订阅、图片、客户端缓存、管理员备份、多语言、截图隐私及隐私 DOM 浏览器套件通过。
- 运行时安全 11 项保持通过；PHP 8.3.36 / Expat 2.10.0 和 FPM 限制保留。
- 生产数据库副本迁移演练：52 张原表内容不变、89 条付款人及分类关联回填、quick_check 与外键检查通过。

Web Push 的加密、权限和浏览器事件验证通过；真实浏览器厂商推送服务到实际设备的送达尚需用户在目标设备启用并验证，测试没有用模拟结果代替真实送达。
